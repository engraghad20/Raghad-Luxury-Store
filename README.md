# Raghade’ Luxury | Premium E-Commerce Platform

بناء وتصميم متجر إلكتروني فاخر لمستحضرات التجميل، بهوية بصرية راقية وتجربة تسوق عصرية تجمع بين الأناقة والبساطة والوظائف المتكاملة، وفق معايير تصميم عالمية (Minimal & Premium).

**Tech Stack:**  
React · TypeScript · Tailwind CSS · Framer Motion · PostgreSQL

**Key Features:**
- تصميم فاخر يدعم اللغة العربية وRTL.
- واجهة تفاعلية وحركات انتقالية سلسة.
- عرض المنتجات والتصنيفات والبحث والتصفية.
- سلة تسوق وإتمام الطلبات وإصدار الفواتير.
- قاعدة بيانات لإدارة المنتجات والمستخدمين والطلبات.
